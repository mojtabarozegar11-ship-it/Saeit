# Quality gates

- Gameplay: verify real bidirectional pipe connections, not only horizontal switches.
- Accessibility: keyboard focus, visible labels, touch targets, reduced motion.
- Reliability: level progression, refresh persistence, invalid storage fallback.
- Performance: Android Chrome and desktop browser tests, no network dependencies.
- Security: no external scripts, no user-data collection.
- Deployment: staged backup and externally verified HTTP before claiming live.
