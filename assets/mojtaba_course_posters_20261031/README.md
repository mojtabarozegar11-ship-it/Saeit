# Mojtaba Roozegar — ten course posters, 31 October 2026

Ten subject-specific, AI-composited photographic campaign posters were created
using the owner-selected portrait archive as an identity reference. The subject
belongs to the full scene; no framed original photograph is overlaid.

- `01`–`10` `.webp`: optimized 900×1125 deliverables for the personal site.
- `01`–`10` `.png`: full-resolution 1122×1402 poster masters, retained outside
  the deployment package and archived in the user's private file collection.
- `social_hub/course_image_data.py`: deterministic embedded WebP payloads used
  by the existing SVG URL routes. The cPanel package upgrader deliberately
  accepts only Python files; its allowlist is not relaxed.
- `scripts/build_mojtaba_course_poster_data.py`: reproducible converter from
  the full-resolution masters to optimized images and Python payloads.

The posters are promotional illustrations of the instructor, not documentary
evidence of lectures already held, enrollment, accreditation or financial gains.
