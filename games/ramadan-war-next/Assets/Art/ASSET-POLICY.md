# Asset acceptance policy

Place only original or licensed for redistribution models/audio in this project. For every asset record: source URL, author, license/version, redistribution scope, SHA-256, original file size, texture dependency list, and rig/animation verification.

The incomplete `soldier-rigged-ccby.glb` and `m24-sniper-ccby.glb` files from the legacy web game must NOT be copied into production here.

No weapon or soldier visual is treated as validated solely because a loader returns success. All imported meshes and their animations must be inspected in Unity Editor and tested on WebGL2 and Android.

Blockout primitive materials in this milestone are generated by code. Licensed visuals, animation, hit reactions, sound and UI art are pending and are release blockers.
