# تَلا برای اندروید

پوستهٔ اندرویدی سبک برای وب‌اپ تَلا. برنامه فقط صفحه‌های HTTPS زیر دامنهٔ `zomorodmelal.ir/tala/` را داخل اپ باز می‌کند؛ پیوندهای بیرونی در مرورگر دستگاه باز می‌شوند.

## حریم محدوده
- نشانی شروع ثابت: `https://zomorodmelal.ir/tala/`
- دامنهٔ اصلی و مسیرهای دیگر در WebView باز نمی‌شوند.
- دسترسی اینترنت تنها مجوز اپ است؛ فایل محلی، محتوای محلی و محتوای HTTP ناامن مجاز نیست.
- قیمت، سفارش، پرداخت، حسابداری و پنل مدیریتی از سرور سایت پیروی می‌کنند؛ این پوسته سرویس جدیدی برای آن‌ها اضافه نمی‌کند.

## ساخت
با JDK 17، Android SDK 35 و Gradle 8.9:

```sh
gradle assembleDebug
```

فایل APK در `app/build/outputs/apk/debug/app-debug.apk` ساخته می‌شود. گردش‌کار GitHub Actions نیز بعد از هر تغییر این پوشه APK را به‌صورت artifact بارگذاری می‌کند.
