# Moj Prop customer quote — signed, unpaid, canonical rendering (Cycle D)

## Operational defect corrected
The old public `/moj-prop-quote/<token>/` view validated structured quote fields but returned `MojPropOffer.manual_quote_text`, interpolating buyer-controlled multiline scope and exclusions as unindented top-level lines. A scoped service note could therefore visually forge `Payment received: ...`, `File delivered: ...`, or a second `Quoted amount: ...` header inside a legitimate signed proposal.

The public GET now renders **only** `make_quote_snapshot(offer)` through `render_public_quote`. Every line of scope/exclusions is prefixed `  | `; any newline convention, including Unicode NEL, remains marked as customer-supplied narrative. The checked heading shows the authoritative request reference, version, service route, product ID, canonical Decimal price/currency, expiry, and not-collected/not-delivered disclaimers. An unidentified digital SKU is not publicly quotable; token creation fails as well as the GET.

## Safety boundary
- The public quote feature remains independently disabled by default (`MOJPROP_PUBLIC_QUOTES_ENABLED`). A signed link alone never authorizes public release, email, invoice, payment, entitlement, delivery or collected revenue.
- The offer contract supports **USD/IRR only**. It is not the native 30 TRX Starter30 order contract; do not convert this quote route into a native TRX charge or claim a Starter30 sale from this file.
- No customer identity, email, private CRM notes, payment wallet, access key, or IP metadata are printed.
- Authorization requires reviewed issued/accepted offers, non-superseded versions, HTTPS, an allowlisted host, a short-lived signed token, and valid terms.
- Existing live Passenger and DB drift, unproven independent full DB/app/media restore, cPanel quota deficit, legal merchant custody, SMTP ownership, tenant isolation and chain finality are **not** solved by this patch.
- **NO MERGE / NO DEPLOY / NO TRON COLLECTION** absent exact-head CI, security review, proven independent backup/restore/rollback and all owner-approved legal gates.
