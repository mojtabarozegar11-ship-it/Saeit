
# Bounded first-customer playbook — research-backed service delivery

## International buyer — diagnose one failure first
Use the existing MojPlayWin services link and approved support email only to **receive** voluntary inquiries. Ask for the public failing route, steps, browser class, the expected business journey and non-sensitive evidence. An observation report must include test environment, timestamps and limitations. A bounded fix becomes a separate scope only after diagnosis and explicit authorization.

## Domestic buyer — quantify one crop
Use the existing ZomorodMelal services/contact path. Ask for product unit and period, actual sold volume, selling unit price, unit-level variable costs and non-duplicated fixed costs. Show a worked synthetic example **only as demonstration**; verify customer-specific data in an approved private transfer. Provide 9-case sensitivity and break-even thresholds with precise exclusions.

## Attribution, not invented progress
Every real lead should be an opted-in independent inquiry, deduplicated. Quote-to-paid uses only approved quotes as denominator. Received funds require settlement proof, not a screenshot of an unpaid invoice. Deliveries require recipient evidence, not merely generated files. If no verification access is available, write UNKNOWN.

## Next authorized acceptance step
After route ownership is independently proven, review lawful collection per jurisdiction, consent, pricing/tax obligations and secure reporting. No automatic marketing, sales emails or purchase links are enabled in this source branch.
