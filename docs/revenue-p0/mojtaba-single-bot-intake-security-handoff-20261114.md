## دو خدمت اولویت‌دار برای اولین فروش مستند
۱. خدمات بررسی/تعمیر محدود Checkout روی MojPlayWin: موجود در متن‌های پیش‌نویس خدمات؛ قیمت‌های فعلی USD صرفاً *محدوده پیشنهادی غیرالزام‌آور* اند، نه قرارداد. خروجی پذیرش در `service-qc-website-checkout-template-en.md`: شاهد خطا، قدم بازتولید، اصلاح محدوده‌دار، بازگشت، تست موبایل، گزارش تحویل.
۲. تحلیل اقتصادی مزرعه و نقطه سربه‌سر روی ZomorodMelal: مسیر استعلام و کد پیش‌نویس وجود دارد؛ قیمت تاییدشده برای این خدمت **نامعلوم** و نباید ایجاد شود. خروجی پذیرش در `service-qc-farm-break-even-template-fa.md`: منابع داده، واحدها، فرمول‌ها، حساسیت قیمت/عملکرد/هزینه، محدودیت علمی و کنترل کیفیت.

**هیچ‌یک در این چرخه از دید سایت زنده، فرم دریافت واقعی، وصول مبلغ و تحویل مشتری مستقل تأیید نشده‌اند.**

## امنیت عملیاتیِ تحویل داده به ربات واحد
- فقط هفت فیلد قبلی `scripts/revenue_dual_offer_qualifier.py` مجاز است: کد خدمت، بسته، تعداد اجزای کار، تعداد مستندات، رضایت تماس، موجودبودن داده، برچسب نمونه.
- `scripts/revenue_intake_io.py` JSON مبهم را رد می‌کند: کلید تکراری از جمله `consent_to_contact`، NaN/Infinity، فرمت نامعتبر، UTF-8 نامعتبر، حجم بالای ۶۴ KiB، symlink و فایل غیرمنظم.
- خروجی استعلام فقط اطلاعات تایپ‌شده غیرشخصی است؛ فایل جدید با ایجاد انحصاری `O_EXCL` و مجوز 0600؛ هیچ فایل ورودی یا خروجی موجود بازنویسی نمی‌شود.
- وضعیت خروجی همواره `inquiry_only`، `not_requested` و `not_delivered` تا رسید و تأیید مستقل. تماس خودکار، صورت‌حساب و تراکنش ندارد.
- قالب‌های QC مخصوص دو خدمت فقط الگو هستند؛ فاقد نام، شماره، رمز، پرداخت، داده تجاری شخصی یا وعده سود.

## شواهد اجرای محلی واقعی
**Python 3.13.5، محیط موقت بدون اینترنت و بدون Django/MariaDB:**
```sh
PYTHONDONTWRITEBYTECODE=1 python -m unittest discover -s tests -p 'test_revenue_intake_io.py' -q
# Ran 15 tests; OK
PYTHONDONTWRITEBYTECODE=1 python -m unittest discover -s tests -p 'test_mojtaba_qualifier_integration.py' -q
# Ran 12 tests; OK
```
**مجموع قابل اتکا روی هفت فایل منتقل‌شده: ۲۷/۲۷ آزمون محلی موفق.** `git hash-object` فایل‌های کدِ اجراشده با SHA blob خوانده‌شده از GitHub یکسان بود. آزمون‌های `test_revenue_dual_offer_qualifier.py` (۶ مورد تازه + قبلی) به مخزن اضافه و به Workflow متصل شدند، اما در این چرخه **روی کل مخزن اجرا نشده‌اند**.
