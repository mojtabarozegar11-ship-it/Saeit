# یک‌مرحله‌ای: سازندگان واقعی F29/F30/F33 + کنترل گلوگاه ۴۰ خانواده

The source repository already had independent fixed-scope native 50-stage builders for F29 DOCX, F30 PPTX and F33 SVG/PNG. This workflow attempts to install and run each of them with the existing pinned private Python toolchain. Each has 48 distinct generated original files plus a separate automated format/integrity reviewer and no commercial owner approval.

New `factory_30_gap_preflight.py` produces 40 executable 48-task engineering acceptance contracts, separates external input requirements from actual artifacts, validates file signatures/ZIP structures and SHA-256 digests, and reads real BUILD50 evidence to report the remaining gaps. It is intentionally a QA/preflight engine, not 40 native manufacturers. Contracts do NOT advance BUILD50 stage receipts. Periodic re-evaluation is attached to the existing five-minute controller script; no cron duplication or public site changes.

Safety: pinned host key, non-root SSH, staged SHA-256, lock, source rollback, no financial action, no owner-approval forgery. A passing result proves only the specifically built fixed-scope technical products and gate checks; independent human review, expert review, website publication and further 27+ specialized producers are separate acceptance items.
