# Zomorod ERP offline V6

Includes offline V5 industry, period, finance-audit and company workflow code, plus the privately isolated payroll code and role/CSRF routes tested separately on GitHub Actions with PHP 8.2 and 8.3: https://github.com/mojtabarozegar11-ship-it/Saeit/actions/runs/40885487587 .

Local PHP 8.4 lacks PDO_SQLite: this environment cannot complete the V6's combined PHP/SQLite behavioral suites. The GitHub run covers payroll and the earlier V1 baselines, not the complete V5/V6 module set. All runnable local SQLite and Python validations must pass. This bundle is source only, and no financial transfer, tax filing, hourly schedule or production deployment is authorized. No 100% ERP readiness claim.
