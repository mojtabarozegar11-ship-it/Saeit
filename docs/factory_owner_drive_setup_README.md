# یک‌بار اتصال امن دو Google Drive به Runner کارخانه

این مرحله **صرفاً احراز هویت و اندازه‌گیری سهمیه است**؛ دستور تهیه بکاپ MySQL یا آپلود داده نیست.

## ۱) ورود از طریق SSH مورد اعتماد

در ترمینال خودتان (نه GitHub Actions، نه ChatGPT) به VPS کارخانه وصل شوید؛ همان حساب سیستم‌عاملی که Runner مجاز با آن کار می‌کند. ترمینال باید تعاملی باشد و هیچ خروجی آن به چت یا لاگ عمومی منتقل نشود.

## ۲) احراز هویت در مرورگر با SSH tunnel

در دستگاه دارای مرورگر (مثلاً Android + Termux)، اتصال SSH مورد اعتماد به VPS را همراه فوروارد محلی پورت callback برقرار کنید:

```bash
ssh -L 127.0.0.1:53682:127.0.0.1:53682 <EXISTING_APPROVED_SSH_DESTINATION>
```

به‌جای `<EXISTING_APPROVED_SSH_DESTINATION>` همان مقصد و کلید SSH ازقبل مجاز خودتان را به کار ببرید. **به دلیل ناشناخته بودن جزئیات اتصال، مقصد جدید حدس زده نشده است.** پورت 53682 در اینترنت عمومی باز نمی‌شود؛ صرفاً روی localhost و تونل احراز‌شده است.

## ۳) اجرای یک دستور در محیط امن VPS

از checkout **PR #2686** روی همان VPS (با دسترسی SSH خودتان)، پس از اطمینان از وجود هر سه اسکریپت در مسیر `scripts/`:

```bash
python3 -B scripts/factory_owner_drive_setup.py --configure
```

این دستور نسخه هش‌سنجی‌شده رسمی rclone را **موقت** تهیه می‌کند و پنجره پیکربندی تعاملی را اجرا می‌کند. دو remote با نام‌های `factory_a` و `factory_b` بسازید. برای پایداری، OAuth client ID متعلق به خودتان ایجاد/استفاده کنید؛ client ID اشتراکی rclone طبق مستندات در سال ۲۰۲۶ در حال بازنشستگی است. فعال‌کردن billing ممنوع است.

برای هر حساب، `root_folder_id` را مطابق زیر ثبت کنید:

- `factory_a` → `191sAkv4A01S9o6zhx-vM5xM7WO31qHPn`
- `factory_b` → `1e6D3Ek4k-4JT_oyEoiY_JejErZFssrC_`

هنگام پرسش `Use web browser` روی VPS، اگر تونل SSH برقرار است «Yes» را انتخاب کنید و URL محلی اعلام‌شده را در مرورگر **همان دستگاه** باز کنید. ابتدا با حساب Google A، سپس B وارد شوید و اجازه دسترسی را در صفحه خود Google صادر کنید.

اگر از تونل استفاده نمی‌کنید، مسیر رسمی headless `rclone authorize drive` روی دستگاهِ دارای مرورگر نیز وجود دارد، اما حاصل آن فقط باید به ترمینال خصوصی VPS منتقل شود، نه به این گفتگو.

## ۴) معیار موفقیت

خروجی به شکل `FACTORY_DRIVE_CONNECTIVITY={...}` تنها باید نشان دهد:
- دو حساب مستقل و فایل اثبات خصوصی F-01 هر دو تأیید شده‌اند؛
- سهمیه `free_bytes_drive_a` و `free_bytes_drive_b` از خود Google گزارش شده؛
- `current_backup_created=false` و `current_factory_size_admitted=false` تا قبل از احراز منبع زنده باقی‌اند.

محتوای `~/.config/rclone/rclone.conf` **محرمانه** است؛ آن را به GitHub، ایمیل، فایل‌خانه یا ChatGPT نفرستید. فایل باید مالک همان حساب سیستم و با مجوز 0600 باشد. پوشه‌های مقصد اصلی از قبل در هر دو Drive ساخته شده‌اند و نیازی به بازسازی نیست.

**مراجع:** https://rclone.org/remote_setup/ ، https://rclone.org/drive/ ، https://rclone.org/commands/rclone_authorize/

## وضعیت محدودیت

پس از اتمام OAuth نیز انجام بکاپ جدید مشروط به هویت واقعی MySQL متصل به Passenger، دامنه کامل رسانه/سایت‌های فرعی، ظرفیت کافی در هر دو مقصد و بازیابی مستقل است. هیچ داده زنده به صرفِ این دستور منتقل نمی‌شود.
