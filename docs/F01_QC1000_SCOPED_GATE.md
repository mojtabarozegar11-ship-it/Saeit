# F01 QC1000 — مسیر واقعی رسیدن به کیفیت ۱۰۰۰

## مشکل اصلاح‌شده
دروازهٔ قبلی یک فهرست عمومی ۱۰۰معیاری را با تأیید حرفه‌ای مخلوط می‌کرد و امتیاز حرفه‌ای را عمداً همیشه خالی نگه می‌داشت. بنابراین حتی با آزمون‌های موفق، مسیر اندازه‌گیری قابل تکمیل نبود.

## راه‌حل
این سیاست برای F01 دقیقاً ۱۰۰ معیار محصول‌محور دارد؛ هر معیار ۱۰ امتیاز و مجموع ۱۰۰۰ امتیاز است. هر امتیاز فقط با یک سند JSON دارای هش دقیق بستهٔ همان نسخه ثبت می‌شود.

دو خروجی جدا هستند:

- **امتیاز مستند ماشینی:** قابل محاسبه توسط کارخانه؛ هدف آن ۱۰۰۰/۱۰۰۰ است.
- **تأیید حرفه‌ای QC1000:** فقط پس از بررسی مستقل متخصص، ممیزی کیفیت و بازبینی حقوقی؛ هیچ کدی آن را جعل یا جایگزین نمی‌کند.

حتی وقتی امتیاز مستند ماشینی به ۱۰۰۰ برسد، قفل تجاری تا دریافت امضاهای واقعی باقی می‌ماند.

## استفاده
```bash
python scripts/f01_quality_1000_machine_gate.py \
  --package path/to/F01.zip \
  --catalog factory_config/f01_quality_100_criteria.json \
  --evidence-root path/to/evidence \
  --output quality-result.json
```

هر سند باید به `saeit.factory.f01-quality-evidence.v1`، شناسهٔ معیار، محصول F01، هش بسته و وضعیت PASS متصل باشد.
