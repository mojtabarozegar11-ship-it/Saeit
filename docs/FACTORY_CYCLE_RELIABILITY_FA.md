# اصلاح پایداری چرخهٔ کارخانه — نصب‌شده

پنج نقص قابل‌بازتولید اصلاح شد: خطای CLI هنگام هم‌پوشانی اجراها؛ توقف تولید سالم در خطای ذخیره‌سازی طراح؛ توقف کل چرخه با RuntimeError ناشناختهٔ یک محصول؛ نرسیدن دستورهای تولیدشدهٔ فاقد آزمون به مسیر بازسازی؛ و خطای شکل نامعتبر cache/شمارش کاذب تولید جدید هنگام بازسازی همان بسته.

دستور compiler-owned فقط با شناسنامه و درخواست اصلیِ تطبیق‌یافته بازسازی می‌شود. نسخهٔ خراب حفظ، نسخهٔ بازسازی‌شده آزمون، و خطا و بازیابی در صف اصلاح ثبت می‌شود. خطاهای محصول نتیجهٔ موفق نمی‌گیرند و دستورهای سالم ادامه می‌یابند. cycle_status و designer_failures وضعیت واقعی را گزارش می‌کنند. تغییر واقعی SHA256 بسته ملاک تغییر محصول است.

اعتبارسنجی: ۶۲ آزمون محلی مرتبط موفق؛ ماتریس Python 3.8 تا 3.14 موفق؛ ۱۲ آزمون یکپارچه روی VPS در پوشهٔ موقت موفق. این آزمون‌ها قفل واقعی، فایل عمدی به‌جای پوشهٔ طراح، خطای محصول، حذف test_*.py و cache معیوب را پوشش می‌دهند. دیتابیس و خروجی اصلی خراب‌سازی نشدند.

نصب و آزمون زنده: https://github.com/mojtabarozegar11-ship-it/Saeit/actions/runs/39243377506
کد بررسی‌شده: https://github.com/mojtabarozegar11-ship-it/Saeit/pull/562

پس از نصب، چرخهٔ اصلی با وضعیت ok اجرا شد؛ زمان‌بندی یک‌دقیقه‌ای حفظ شد. ۵ دستور ثبت‌شده و ۹ نسخهٔ انبار فنی مشاهده شد؛ تعداد نسخه‌ها برابر تعداد محصول تجاری جدید نیست.

این اصلاح، خودترمیمی محدودِ کد تولیدشده و تداوم تولید را تقویت می‌کند. موتور بازنویسی و ارتقای عمومیِ کد کارخانه نیست. اختراع عمومی، آداپترهای اجرایی همهٔ ۴۰ خانواده، تأیید علمی پرونده‌های پژوهشی و ۱۰۰ نسل ارتقای اثبات‌شده هنوز با این تغییر محقق نمی‌شوند.
