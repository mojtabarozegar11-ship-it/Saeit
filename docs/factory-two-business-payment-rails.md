Two independently specified payment routes: MojPlayWin (mojplaywin.com) uses existing crypto gateway and intended TRX/ETH; Zomorod Melal (zomorodmelal.ir) uses Bank Shahr linked Iranian rial merchant gateway. Bank Shahr is the owner-confirmed bank, not necessarily the PSP; actual PSP, merchant ID and callback/verify API are unverified. The factory records 80 internal site-family routes (40 per site), with no customer checkout, keys, network calls, charges or publication. For cryptocurrency, independently verify destination wallet ownership, token and chain identity, amount, confirmations, unique tx hash and order before delivery. For Bank Shahr, use a securely configured actual PSP with server-to-server reference verification, amount, merchant identity, idempotency and settlement confirmation; bank browser redirects do not prove payment. Product rights, price approval, terms, refund and secure fulfillment also remain blocked. No live sales or real revenue is claimed by this private staging step. Stripe is not used. Existing VPS scheduler updates metadata; no new cron, no changes to public websites.
