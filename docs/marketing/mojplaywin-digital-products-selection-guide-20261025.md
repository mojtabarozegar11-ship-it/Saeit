## A two-minute decision check

1. **What must you produce?** If it is a study schedule and game review, choose the chess book. If it is a family reading experience, choose Taniya. If it is an editable studio website, choose Atelier.
2. **Can you use the format?** You need a PDF reader for the books; for the website kit, you need a way to edit and host HTML/CSS/JavaScript.
3. **Do you have the time and skills?** The chess material needs repeated practice. Shared reading needs an adult or confident reader. The website kit needs editing, testing and deployment.
4. **Is the licence suitable?** Read the product's current licence. The Atelier listing describes a non-exclusive one-site/client licence, not a general resale right.
5. **Is the payment method workable for you?** Product pages describe account sign-in and an order-specific TRX invoice; do not send funds before seeing the actual invoice and network details.

## Purchase-path transparency

The public listings currently describe the following sequence: open a product page → register or sign in → request the order-specific TRX invoice → review the exact TRX amount and receiving address → pay using a compatible TRON wallet → wait for independent on-chain confirmation → access the private download according to the order state.

A TRON address copied from an old screenshot, chat message or third-party advertisement is not an invoice. Never substitute USDT for TRX or send funds over another network unless the actual invoice explicitly supports it.
