# Agricultural Field-Trial Preregistration and Data Integrity

*Free scientific planning template for the Mojtaba Roozegar research profile, 25 October 2026. Not a registered protocol, approved study or published research result.*

## Purpose
Field studies are affected by weather, spatial gradients, missing plots and many possible endpoints. A dated, versioned protocol written before outcome inspection distinguishes planned confirmatory analysis from later exploration. Amendments are possible but must be dated and explained.

## 1. Identity and hypothesis
Title; protocol ID and version; date; investigator; host; crop and cultivar; season; field history; research question; primary hypothesis and direction; independent rationale and references; funding and conflicts of interest.

## 2. Experimental unit and allocation
Define whether the independent unit is a plant, pot, plot, field or farm. Specify treatments and control, doses, application schedule, randomization procedure, blocks, number of replicates, buffer zones, spatial positions and contamination prevention. Multiple plants inside a treated plot do not automatically provide independent plot-level replication. Record allocation seed and preserve the original allocation table before outcomes.

## 3. Primary and secondary outcomes
Define one primary endpoint, its unit, timing, instrument, sampling method and handling of border rows. For example, plot-level marketable yield at a declared moisture basis. Specify secondary outcomes, calibration, measurement blinding where feasible, missing-value codes, outlier handling and data-quality checks. Freeze definitions before results are observed.

## 4. Analysis plan
State the estimand, model, planned contrasts, covariates, fixed/random effects where appropriate, confidence or uncertainty intervals, multiplicity policy and sensitivity analyses. The statistical method must respect the experimental unit. Explain sample size from plausible effects, variability and logistical limits; do not claim a universal replicate count.

## 5. Safety, rights and provenance
Document land access, genetic material permissions, worker safety, environmental controls, required ethics or biosafety review, data dictionary, storage access, checksums, anonymization and retention. Preserve original measurements and a reproducible analysis script. Never present self-review as independent peer review.

## 6. Reporting ledger
| Item | Evidence |
| --- | --- |
| Original timestamp | Repository commit or registry ID |
| Randomization | Allocation file and method |
| Primary outcome | Frozen protocol version |
| Amendment | Dated change and reason |
| Exclusions | Transparent raw-to-analysis flow |
| Deviations | Planned versus observed |
| Results | Effect size, uncertainty, limitations |

## Decision form
Protocol status (draft/preregistered/amended/completed); version and timestamp; primary endpoint frozen (yes/no); approvals (complete/pending/not applicable); independent reviewer only if actually appointed; unresolved threats; sharing plan; decision and signature.
