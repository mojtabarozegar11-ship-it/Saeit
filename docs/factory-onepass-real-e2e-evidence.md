# Factory one-pass VPS proof: scope and integrity

This job runs once on the existing VPS with pinned SSH host fingerprint. The script verifies the 3000 registered support tool bindings, executes one real tool fixture per binding, executes 400 real family-scoped tool operations per router tick, submits eight labelled test requests to the same private production-tool request queue, checks returned results and SHA digests, checks rejection of an unauthorized role label, and independently recalculates the 50-stage product inventory from the live build-50 evidence files.

Critically, these eight labelled test requests are *synthetic probes submitted by the CI proof script*, not messages emitted by eight autonomous agents. Their success does not prove that each real historical agent/robot/worker is alive or using tools. The 3000 registered bindings are interfaces to 75 underlying operations, not 3000 independent builders. The verified BUILD50 count is reported as observed; other families remain unproven.

Writes a private JSON receipt `private/autonomous-product-cycle/evidence/tool-router-onepass/e2e<runid>-receipt.json` and prints the receipt SHA-256 in GitHub job logs. Does not modify cron, stores, payments, ownership approval or publish products. The working proof source is SHA-256 verified over the existing GitHub→VPS relay.

Validation gates: `ONEPASS_VPS_QUEUE_TOOL_ROUTER=PASS`, `ONEPASS_VPS_NATIVE_PRODUCT_50STAGE_INDEPENDENT_AUDIT=PASS`, and `ONEPASS_VPS_ALL_AGENTS_AND_ALL_40_BUILDERS=NOT_PROVEN` are independent findings, not contradictory status markers.
