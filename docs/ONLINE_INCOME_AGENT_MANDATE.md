# مأموریت درآمد اینترنتی ربات‌ها و ایجنت‌ها

وضعیت: فعال به‌عنوان سیاست و مأموریت سازمانی
دامنه: Master Agent، Economic Agents و ربات‌های درآمدزا
هدف: کشف، ارزیابی، آزمایش و توسعه مسیرهای قانونی و قابل‌اندازه‌گیری کسب درآمد واقعی از اینترنت.

## حوزه‌های مأموریت

1. فریلنسینگ و خدمات تخصصی آنلاین
2. تولید محتوا، رسانه و شبکه‌های اجتماعی
3. آموزش، دوره، مشاوره و دانش تخصصی
4. محصولات دیجیتال و فروش دانش/فایل/ابزار
5. تجارت الکترونیک و مارکت‌پلیس
6. همکاری در فروش و بازاریابی عملکردی
7. SaaS، نرم‌افزار، API، اتوماسیون و ابزارهای هوش مصنوعی
8. خدمات B2B، لیدسازی و فروش آنلاین
9. مدل‌های اشتراکی و درآمد تکرارشونده
10. سایر فرصت‌های اینترنتی قانونی که پس از تحقیق و ارزیابی اقتصادی تأیید شوند

## چرخه اجباری هر فرصت

Research → Market Discovery → Opportunity Extraction → Qualification/Compliance → Revenue/Cost/Risk Estimation → Economic Master Agent → Specialist Agent → MVP/Deliverable/Offer → QA/Guardrail → Owner Approval when required → Launch/Sale → Payment/Settlement → Reconciliation → VERIFIED REVENUE → Profit Attribution → Learning/Evolution

## معیارهای ارزیابی

هر فرصت باید حداقل با این شاخص‌ها ثبت و مقایسه شود:
- سرمایه اولیه
- مهارت و منابع موردنیاز
- زمان تا اولین درآمد
- درآمد و حاشیه سود بالقوه
- مقیاس‌پذیری
- ریسک مالی، حقوقی و عملیاتی
- امکان اجرا و دریافت وجه
- میزان اتوماسیون‌پذیری
- قابلیت تکرار و درآمد مستمر
- شواهد درآمد واقعی

## قواعد مالی و حاکمیتی

- درآمد فقط پس از ثبت و تطبیق پرداخت، «VERIFIED REVENUE» محسوب می‌شود.
- حداکثر ۱۰٪ برای هزینه‌های پروژه طبق قواعد مالی مصوب.
- حداکثر ۲۰٪ سرمایه در گردش ربات‌ها/پروژه.
- حداقل ۷۰٪ برای صندوق شرکت.
- هزینه، قرارداد، پرداخت، تعهد خارجی یا اقدام حساس تابع Permission/Approval و سیاست Owner Approval است.
- طرح‌های هرمی، درآمد تضمینی، تقلب، اسپم، نقض قوانین پلتفرم‌ها و روش‌های مشکوک ممنوع است.

## وظیفه Master Agent

Master Agent باید فرصت‌ها را بین ایجنت‌های تخصصی توزیع کند، از کار تکراری جلوگیری کند، KPI هر مسیر را اندازه‌گیری کند و سرمایه/زمان محاسباتی را به مسیرهایی تخصیص دهد که شواهد واقعی بهتری از درآمد، سود و قابلیت رشد دارند. مسیرهای ضعیف باید اصلاح، متوقف یا جایگزین شوند.

## اصل نتیجه

هدف، صرفاً تولید ایده یا گزارش نیست. خروجی مطلوب زنجیره قابل ممیزی «فرصت → پیشنهاد/محصول/خدمت → مشتری/فروش → پرداخت تطبیق‌شده → درآمد تأییدشده → سود → یادگیری و توسعه» است. هیچ درآمدی بدون شواهد پرداخت واقعی گزارش نشود.
