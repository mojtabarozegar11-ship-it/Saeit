## New substantive correction
Distinguish **source discovery/calibration** from **review screening**. Three new source audits (Monteiro, Wang/Xu, Nxumalo) have publisher-verified identities and analytic notes, but none was retrieved through a frozen bibliographic database search or screened against an author-approved final eligibility protocol. Therefore:
- Number identified through formal database searches: **NOT AVAILABLE**, not zero.
- Deduplicated search records: **NOT AVAILABLE**.
- Number screened/included/excluded: **NOT AVAILABLE**.
- Human dual-reviewer agreement: **NOT PERFORMED**.
- Risk-of-bias appraisal: **NOT PERFORMED**.
- Similarity/plagiarism software scan: **NOT PERFORMED**. Source-linked original prose is not a substitute for a licensed similarity report.

## Workflow controls
Each actual database record requires platform ID, export file, query, UTC timestamp, checksum, deduplication linkage, human reviewer decisions and reason. Exclude reason codes: wrong population; no actionable irrigation DSS; model-only/no field; no crop farming; secondary review; unavailable text (record attempts); other documented. Borderline autonomous control and generic WST survey go to human adjudication, not automatic exclusion. No false PRISMA flow graphic is to be generated.
