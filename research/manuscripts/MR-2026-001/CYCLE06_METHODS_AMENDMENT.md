# MR-2026-001 — Original prospective methods amendment v0.2
Prepared 2026-10-24. **Proposed methods only; not a report of completed work.** Author/information specialist must approve before protocol freeze.

## Separating intervention construct from measurement
For each candidate source, chart the unit as (study, intervention, actor, outcome, comparator, observation window). Intervention type is coded independently of outcome type. An irrigation DSS requires a documented, actionable irrigation timing/depth/volume/allocation recommendation or algorithmic decision; a generic water-saving technology adoption questionnaire is insufficient. A sensor-only reading without advice is not a DSS. An autonomous controller may be mapped as a separate automation stratum if authorized; it is never coded as a farmer's adoption decision by default.

## Adoption ladder and measurement hierarchy
Record distinct events: (0) system proposed, (1) advice delivered, (2) supervised demonstration, (3) recommendation followed with timestamped field evidence, (4) voluntary independent repeat use, (5) sustained use across seasons. Record denominator, follow-up and attrition for each stage; do not impute later stages from an earlier one.
For each endpoint distinguish M-meter (independently metered irrigation water), M-proxy (calibrated flow × actuator duration or logged application), M-yield (harvest measurement), O (observed adherence), S-intent (stated intention), S-behavior (survey-reported uptake), P-physical (simulated ETc or predicted water savings), P-economic (modeled payback). A paper may contribute multiple classes. No class alone establishes causality.

## Comparator and leakage checks
Document comparator source (concurrent randomized control, nonrandomized paired field, before/after, historic baseline, or modeled counterfactual); crop/soil/irrigation technology, season, unit of allocation, exposure time, loss-to-follow-up and cointerventions. For ML studies record target origin: a model-derived FAO-56 ETc target is not independently metered evapotranspiration; cross-validation against such a target tests model agreement. Audit spatial/temporal splitting claims against reproducible code where possible, and flag unverifiable splits as unclear rather than erroneous.

## Analysis (prospective)
Present descriptive evidence maps by intervention, actor, adoption stage, outcome provenance and comparator. Only compare numerical results within comparable endpoints and units. Report null and adverse findings. Do not calculate pooled water savings, uptake, or economic return from heterogeneous case studies. Chart source-reported effect estimates as source results with uncertainty and provenance, not as independently validated review effects.

## Author decision gate
Provisional main scope: farmer-facing advice and actual human use; autonomous control and generic WST intention/adoption papers in separate contextual strata. This is **not yet author-approved**. If scope is broadened, revise the title, eligibility criteria and novelty audit *before* running formal searches.
