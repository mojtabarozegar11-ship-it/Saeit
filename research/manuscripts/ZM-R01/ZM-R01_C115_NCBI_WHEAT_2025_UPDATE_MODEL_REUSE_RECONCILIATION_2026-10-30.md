# ZM-R01 — wheat RefSeq update evidence reconciliation (C115, 2026-10-30)

**Scientific stage: SOURCE-VERIFIED REFERENCE ANNOTATION; no FASTQ or experimental expression data.** Both NCBI reports use **IWGSC CS RefSeq v2.1, GCF_018294505.1**, so the comparison is an *annotation-release* comparison on the same assembly, not a new reference genome or independent validation experiment.

The original [2021 Release 100](https://www.ncbi.nlm.nih.gov/refseq/annotation_euk/Triticum_aestivum/100/) reports **142,406 mRNAs**, all model RefSeq XM_; **103,787 protein-coding genes** and **142,442 CDSs**. The original [2025 update GCF_018294505.1-RS_2025_04](https://www.ncbi.nlm.nih.gov/refseq/annotation_euk/Triticum_aestivum/GCF_018294505.1-RS_2025_04/) reports **262 known NM_ mRNAs + 142,152 model XM_ mRNAs = 142,414 total mRNAs**, **103,793 protein-coding genes** and **142,450 CDSs**. This reconciles the 2025 transcript subtypes exactly: 262 + 142,152 = 142,414; net mRNA difference from 2021 is **+8**, and net coding-gene difference **+6**.

**Crucial source-method distinction:** NCBI explicitly says the 2025 release placed then-current known NM_/NR_ transcripts and retained still-current model RefSeq predictions from Release 100; **the models were not recalculated** for this update. Therefore neither +8 mRNAs nor +6 coding-gene features establishes experimentally discovered genes, differential expression, new wheat variants, new assembly bases or a new sample-level biological effect. CDS features (142,450) and mRNA features (142,414) are different counts and must not be forcibly matched one-to-one.

**Reproducible unit contract:** accession GCF_018294505.1; 2021 public submission 2021-10-26; 2025 update public submission 2025-04-18; known transcript cutoff 2025-04-16. Future FASTQ inference requires real BioProject/SRA accession, sample sheet, reference FASTA/GTF checksums, aligner parameters, QC and biological replicates. These are absent, so **ZM-R01 empirical manuscript remains BLOCKED**. No fabricated reads or validation claim.
