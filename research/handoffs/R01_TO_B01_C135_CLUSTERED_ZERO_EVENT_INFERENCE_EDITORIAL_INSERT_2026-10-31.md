# R-01 → B-01 | Chapter 20 zero-event inference editorial insert | 31 October 2026

**Owner B-01; independent R-01 scientific handoff only. No shared book file edited.**

## Copy-ready conservative wording
> In the inspected set of 24 units, no target event was recorded. This describes only the inspected units under the stated sampling and observation protocol. It does not establish zero risk in the production population. If units are clustered within common batches, farms, rooms, sampling dates or handling chains, treating all 24 as independent binomial trials would be unjustified. Any inferential bound must be withheld until the independent sampling unit, event definition, ascertainment sensitivity and clustering structure are documented.

## Conditional arithmetic for an independent Bernoulli design only
If and **only if** all 24 trials are independent, identically sampled, adequately ascertained Bernoulli units with zero observed events, the exact one-sided 95% upper limit is **1 − 0.05^(1/24) = 11.73%**; the upper end of a central two-sided exact 95% interval is **1 − 0.025^(1/24) = 14.25%**. These are not interchangeable and **neither applies** merely because 24 samples were processed. If samples share a batch or other cluster, an effective independent n must be justified or no population bound reported. Zero detections also depend on test sensitivity and the event definition.

## Release gate for B-01
