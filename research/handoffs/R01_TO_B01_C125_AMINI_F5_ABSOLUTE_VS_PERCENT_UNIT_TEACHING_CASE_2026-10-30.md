# B-01 independent scientific teaching insert — F5 water-productivity units
Source: Amini et al. (2025), Scientific Reports 15:42480, DOI https://doi.org/10.1038/s41598-025-26567-z
Scope: editorial handoff to B owner; not inserted into any live book or website.

**Case:** For orchard F5, the original article's Table 4 displays DSS-treatment irrigation-input water productivity 8.4 kg/m³ and control 4.6 kg/m³ (both rounded). Its Results describes an increase of approximately 3.8 kg/m³. Table 5 instead prints +3.87 in a column headed 'Increase in water productivity (%)'. Explain whether these quantities are interchangeable.

**Worked answer:** Absolute displayed difference = 8.4−4.6 = **+3.8 kg/m³**. Conventional relative change using control denominator = (8.4−4.6)/4.6 ×100 = **+82.61%**, not +3.87%. The Table 5 magnitude +3.87 could be an unrounded absolute difference with a mislabeled header, but source data are unavailable and this is a **hypothesis**, not a verified correction. F7 is independently inconsistent across published prose and table values and must not be silently repaired. Teaching emphasis: units, denominators, rounding, and source provenance are separate QA gates.

**Editorial acceptance:** Retain the original article citation, clearly mark calculated values as calculations from rounded displayed numbers, prohibit use as independently measured farmer adherence, causal savings, or verified exact unrounded effects.
