Optional website measurement

We ask permission before collecting optional visit and purchase-click events. Declining does not limit browsing or checkout.

If you opt in, this website sends only the page category, event type (such as viewing a page or clicking the buy link), short campaign labels, a random browser-tab session token and server-side time to the website's own measurement endpoint.

No form field values, purchase emails, wallet addresses, transaction IDs, complete URLs, IP addresses or account identifiers are written to this analytics event file. Routine web-server access logs may be generated separately for operations and security. No third-party analytics provider receives these events.

Consent is stored in your browser until changed. A random session ID is stored in browser session storage, with a 30-minute activity window; it is not a payment or login identifier. The private measurement files are accessible only to the site operator. Their maximum operational retention target is 30 days, subject to the operator's backup and deletion controls. Statistics are approximate: browser or bot activity can misclassify visits. Only verified server settlement counts as a sale.
