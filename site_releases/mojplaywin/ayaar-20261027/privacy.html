DATA STEWARDSHIP / EVIDENCE PROTECTION

Trust begins with
clear boundaries.

The AYAR case service asks for only the information needed to register a product dossier and support its review. This notice describes its implemented safeguards and limitations. It is not a claim of independent security certification.

01 / INFORMATION

What is collected

Product title, version, category, scope, references, optional email, rights declaration, staff requests, applicant follow-ups, case history and optional PDF/image/text evidence. Payment credentials and identity-document uploads are not requested.

02 / LOCATION

Where it is stored

Cases use AYAR's isolated private storage, separate from MojPlayWin's commerce database. Attachments are outside the public web directory and downloadable through an authenticated staff-only API.

03 / ACCESS

Who can see it

Case owners need their one-time private access key. Site staff must already be authenticated with staff privileges to access review queues and evidence. Human reviewer independence must also be declared.

04 / PUBLICATION

Public reporting

A minimal summary may appear in the public registry only if the applicant opts in and an actual reviewer-attested report is completed. Uploaded evidence and email addresses are never listed in that registry.

05 / SECURITY

Technical protections

Same-origin CSRF controls, case-key verification, submission and follow-up quotas, restricted file signatures, private file permissions and HTTPS transport. File hashes check consistency; downloadable report JSON is not digitally signed.

06 / LIMITATIONS

What is not guaranteed

Storage is not advertised as end-to-end encrypted. Submitted files are not guaranteed malware-free. Automatic security scanning, independent accreditation and verified deletion of hosting backups are not included.

CONTROL & RETENTION

Your case remains yours.

A person holding the exact case identifier and access key can request removal from active AYAR storage using the tracking page. Case credentials are not emailed or stored in your browser by this tool. If lost, automated recovery is unavailable.

Active case records remain stored until removed by the authorized case holder or an operator under a documented retention process. There is no claim here that historical hosting backups are erased immediately. Do not upload confidential material unless the current access and retention arrangements meet your requirements.

DATA MINIMIZATION

Submit references first

For high-value software, unpublished manuscripts or large media assets, start with a safe product description, version and non-secret documentation. Establish a reviewed scope and protected delivery arrangement before sharing confidential source files.

TRANSPARENCY

Not a legal or accreditation shortcut.

AYAR is operated as a MojPlayWin initiative. This operational disclosure must be supplemented with jurisdiction-specific contractual terms, verified controller contact information and any required privacy notices before handling sensitive regulated data or offering formal paid certifications.
