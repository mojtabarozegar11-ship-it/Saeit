3. Practical image delivery field notes

Each note addresses a distinct publishing decision. Sources below are documentation references, not performance guarantees.

01 · Confirm the actual encoder format

Canvas toBlob may silently return PNG if the requested format is unsupported. Inspect the returned Blob type before naming a file .webp; this tool refuses a mismatched result.

Source: MDN Canvas toBlob
02 · Measure savings against the original

Compare byte counts, not file extensions. A low-complexity PNG can be smaller than a high-quality WebP. If the result grows, try a smaller dimension or different quality and inspect sharp edges.

Source: MDN encoder quality
03 · Choose responsive widths from layout slots

Start with the CSS display width on phones, tablets and desktop, then account for device pixel density. Generating enormous images for a 300px card wastes bandwidth.

Source: MDN img sizes
04 · Use accurate width descriptors

Every width descriptor in srcset must match the real pixel width of that specific file. Do not label a 640px image as 1280w. This tool derives descriptors from canvas output dimensions.

Source: MDN srcset
05 · Keep sizes aligned with the actual layout

Sizes tells the browser how wide the image is expected to display at each viewport width. The generated snippet is a starting point; adjust breakpoints to your CSS grid and content column.

Source: MDN sizes
06 · Reserve dimensions to avoid layout shifts

Declare width and height or a matching aspect ratio. Without reserved space, text can jump when a late image loads, degrading readability and interaction.

Source: MDN img width and height
07 · Write meaningful alt text

Describe the image's purpose in context, not a list of search keywords. Decorative images can use empty alt text. This tool never fabricates alt text from a filename.

Source: MDN alt attribute
08 · Avoid lazy loading the primary hero image

The image likely to be the page's main visual should normally be discoverable early. Use lazy loading for images farther down the page, and verify the result with actual browser measurements.

Source: MDN loading attribute
09 · Treat fetchpriority as a selective hint

High priority is useful for a truly important above-the-fold image, but making every image high priority defeats the signal. Start with the likely LCP image and test.

Source: MDN fetchpriority
10 · Use picture for art direction and fallbacks

When a mobile crop conveys different information than a desktop crop, a picture element can select sources by media query. Keep a suitable img fallback and meaningful alt text.

Source: MDN picture

Browser-side conversion processes only the selected image pixels. Test downloaded images on your actual target devices. EXIF metadata may not survive canvas re-encoding. This is a standalone tool, not a cloud file store.
