04 · QUESTIONS

Practical answers before commissioning a project

Can you work with an existing website rather than starting over?

A safe redesign begins with the current URL inventory, content, media, customer flows and deployment boundaries. When a project contains protected applications or integrations, changes must be isolated and verified before publication.

Do you build Django administration and business workflows?

Django supports custom admin interfaces, permissions, data modeling and API-driven workflows. The precise features depend on a project specification, user roles and an agreed security review.

Can existing payment and product records be preserved?

Preservation should be a written acceptance condition. Before editing commerce code, inventory products, prices, files, order records and provider settings; take recoverable backups and compare record fingerprints before and after deployment.

How are AI features evaluated before public release?

Set explicit data boundaries and quality criteria, test realistic failure scenarios, keep humans responsible for sensitive decisions and clearly distinguish prototypes from production-ready services.

How do we estimate budget and timeline?

Estimate only after reviewing scope, existing systems, assets, accessibility goals, dependencies and integration uncertainty. A phased discovery deliverable reduces ambiguity before a larger build is authorized.

Do you guarantee perfect scores or commercial results?

We set measurable targets and publish verified evidence, but performance varies with production hosting, content, devices and third-party dependencies. No untested score, ranking, sales figure or integration is guaranteed.
