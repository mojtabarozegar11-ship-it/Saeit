SUPPORT · PRACTICAL HELP

Find the right solution and a clear next step

Start with the affected product or service, the result you expected, what actually happened and the relevant version or device. A useful support request never needs a password, private key or wallet recovery phrase.

Digital file does not open

Confirm the file finished downloading and compare its extension with the product description. Try a compatible reader, check available storage and record the error without uploading personal documents into an unverified channel. If multiple customers report a defect, the source package needs correction rather than an endless workaround.

Checkout or payment question

Preserve the order reference and the public blockchain transaction identifier, if applicable. Do not attempt a second transfer until the first transaction has been reconciled. Never disclose wallet seed phrases, signed authentication messages or private keys. Payment confirmation and delivery must be verified by the official checkout process.

Game or software problem

State your device, operating-system version, software version and the exact steps needed to reproduce the problem. A screenshot of a visible error can help, but remove account details and private information first. Check published compatibility notes and known limitations before reinstalling or removing data.

Professional service request

Describe the business objective, intended users, deliverable, essential constraints, language needs and any relevant deadline. A bounded first milestone and acceptance checklist make project proposals easier to compare. Do not send confidential files until a verified and appropriate transfer channel is agreed.

Support guidance is informational. Response times, refunds, payment status and active service availability must be established from verified records, not inferred from this page.
